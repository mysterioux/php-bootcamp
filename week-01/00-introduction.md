# What is PHP?

PHP (Hypertext Preprocessor) is a popular server-side scripting language used to build dynamic websites and web applications.

It is commonly used to:

- generate HTML dynamically
- connect to databases such as MySQL
- process forms and user input
- create login and user management systems
- build CMS platforms and e-commerce sites

PHP runs on the server, and the browser only receives the final HTML result.

Example:

```php
<?php
$name = "Alice";
echo "Hello, $name!";
?>
```

This outputs:

```text
Hello, Alice!
```

PHP is widely used because it is beginner-friendly, powerful, and supported by most web hosting providers.

PHI is an interpreter language not a compiled language. It requires a SERVER to run.
