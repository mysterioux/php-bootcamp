# PHP Bootcamp: 12-Week Curriculum

A structured weekly path inspired by the topics in [Learn PHP the Right Way](https://github.com/ggelashvili/learnphptherightway-outline). Aim for 5–8 hours of study and practice each week. Build one small application throughout the course, adding to it as you learn.

## Curriculum

| Week | Focus                      | Topics                                                                                                  | Weekly deliverable                                                                    |
| ---- | -------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1    | Setup and PHP basics       | Install PHP and Composer; command line; PHP tags and syntax; comments, variables, constants, and output | A command-line program that introduces itself and prints formatted information.       |
| 2    | Types and operators        | Scalar and compound types; type declarations; casting; operators; expressions and comparisons           | A unit converter with validated input and clear output.                               |
| 3    | Control flow and functions | Conditionals; loops; functions; arguments and return types; scope                                       | A command-line quiz or number-guessing game made from reusable functions.             |
| 4    | Arrays and strings         | Indexed and associative arrays; iteration and array functions; string operations and formatting         | A report generator that summarizes a collection of records.                           |
| 5    | Files, dates, and errors   | Date/time handling; file operations; JSON; error reporting; exceptions                                  | A JSON-backed task list that handles missing files and invalid data.                  |
| 6    | Object-oriented PHP        | Classes and objects; constructors; properties and methods; visibility; inheritance and composition      | Model a small library or inventory domain with several related classes.               |
| 7    | Modern PHP and Composer    | Namespaces; autoloading; Composer dependencies; interfaces; traits; enums and modern language features  | Refactor the domain project into namespaces and install a useful Composer package.    |
| 8    | Web and HTTP fundamentals  | Request/response lifecycle; HTTP methods and status codes; forms; headers; cookies and sessions         | A form-based PHP page with server-side validation and session feedback.               |
| 9    | SQL and persistence        | Relational data; SQL queries; schema design; PDO; prepared statements; transactions                     | Persist application records in SQLite or MySQL using PDO safely.                      |
| 10   | Application structure      | Routing; controllers; templates; configuration; environment variables; separation of concerns           | A small multi-page application with clear routing and reusable templates.             |
| 11   | Security and testing       | Input validation; output escaping; CSRF protection; password hashing; PHPUnit; debugging                | Add tests and a basic authentication flow; review the app for common security issues. |
| 12   | Capstone and delivery      | Code quality; logging; deployment basics; documentation; final review                                   | Finish and document a CRUD application, run its tests, and prepare a brief demo.      |

## Weekly study routine

1. Read the relevant subjects in the linked outline, then check the official PHP documentation for details.
2. Type and modify examples yourself; test both expected and invalid inputs.
3. Complete the weekly deliverable and commit the work to version control.
4. Review the code for readability, correctness, and security before moving on.

## Capstone suggestions

Choose a task manager, reading tracker, or inventory app. Keep the scope manageable and incrementally add persistence, validation, tests, and documentation. By the final week, aim to support create, read, update, and delete operations and provide clear setup instructions.
